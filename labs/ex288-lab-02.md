# Lab EX288-02 — Builds, ImageStreams, Routes with TLS

Target bank domain: `image-management`, `routes-ingress`, `build-deploy`.

## Setup

```bash
oc new-project lab-dev-02
```

## Part A — S2I build

1. Create an ImageStream `quote-nginx`.
2. Create a BuildConfig `quote-nginx` using **Source** strategy with
   `https://github.com/sclorg/nginx-ex` and builder image
   `registry.access.redhat.com/ubi8/nginx-120`.
3. Trigger the build and wait for completion.

```bash
# verification
oc get buildconfig -n lab-dev-02 quote-nginx -o jsonpath='{.spec.strategy.type}'
oc get imagestream -n lab-dev-02 quote-nginx -o name
oc get builds -n lab-dev-02 --no-headers | awk '{print $2}' | sort -u
```

Expected: `Source`, an imagestream, and the build finishing (Complete).

## Part B — Image change trigger

4. Tag a second image into the stream:
   `oc tag quay.io/openshift-examples/quotes:latest quote-nginx:new` and
   confirm the ImageStreamTag exists.

```bash
# verification
oc get is quote-nginx -n lab-dev-02 -o jsonpath='{.status.tags[*].tag}'
```

Expected output contains `new`.

## Part C — TLS routes

5. Deploy a `secure-app` (any nginx image).
6. Create three routes exposing it: **edge** (edge termination, default cert),
   **passthrough**, and **reencrypt** (reencrypt termination, default cert),
   each with distinct hostnames.

```bash
# verification
oc get routes -n lab-dev-02 --no-headers -o custom-columns=NAME:.metadata.name,TERM:.spec.tls.termination
```

Expected: three routes with terminations `edge`, `passthrough`, `reencrypt`.
