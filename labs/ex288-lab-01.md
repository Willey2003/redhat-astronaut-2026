# Lab EX288-01 — Deploy, expose, configure

Target bank domain: `build-deploy`, `routes-ingress`, `app-configuration`.
Run on your cluster, verify with the checks, then confirm with Mastery-mode
attempts in the `ex288-developer` bank.

## Setup

```bash
oc new-project lab-dev-01
```

## Part A — Deploy from an image

1. Create a Deployment `quote` from image `quay.io/openshift-examples/quotes:latest`.
2. Expose it as Service `quote-svc` on port 80 targeting container port 8080.
3. Create a Route `quote` (plain HTTP) with the default host.
4. Scale the Deployment to 3 replicas and confirm rollout.

```bash
# verification
oc get deploy -n lab-dev-01 quote -o jsonpath='{.status.readyReplicas}'
oc get svc -n lab-dev-01 quote-svc -o jsonpath='{.spec.ports[0].targetPort}'
oc get route -n lab-dev-01 quote -o jsonpath='{.spec.to.name}'
```

Expected: `3`, `8080`, `quote-svc`.

## Part B — ConfigMaps and Secrets

5. Create ConfigMap `app-cfg` with key `LOG_LEVEL=debug`.
6. Create Secret `db-secret` with key `password` (value base64).
7. Add a second Deployment `worker` that mounts `app-cfg` as a volume and sets
   `DB_PASSWORD` from `db-secret`.

```bash
# verification
oc get configmap -n lab-dev-01 app-cfg -o jsonpath='{.data.LOG_LEVEL}'
oc get secret -n lab-dev-01 db-secret -o jsonpath='{.data.password}' | base64 -d
```

Expected: `debug` and your plaintext password.

## Part C — Health probes and rollout

8. Add liveness and readiness probes to `worker` on path `/healthz` port 8080.
9. Edit `quote` image to a new tag (`:v2`) and roll back with `oc rollout undo`.

```bash
# verification
oc get deploy -n lab-dev-01 worker -o jsonpath='{.spec.template.spec.containers[0].livenessProbe.httpGet.path}'
oc rollout history deployment/quote -n lab-dev-01
```

Expected: `/healthz` and a history with ≥ 2 revisions.
