# Lab EX280-01 — SCCs, RBAC and quotas

Target bank domain: `authentication-security`, `application-lifecycle`.
Do the whole lab on your cluster, then verify with the checks. Repeat the
matching exam-bank attempts in Mastery mode to confirm.

## Setup (run once)

```bash
oc new-project lab-01
```

## Part A — ServiceAccount + RBAC

1. Create a ServiceAccount `deployer` in `lab-01`.
2. Create a Role `pod-manager` that allows `get, list, create, update, delete`
   on `pods` and `deployments`.
3. Bind it to `deployer` with a RoleBinding `deployer-pods`.
4. Verify the SA can list pods using its token.

```bash
# verification
oc get sa -n lab-01 deployer
oc get role -n lab-01 pod-manager
oc get rolebinding -n lab-01 deployer-pods -o jsonpath='{.subjects[0].name}'
oc auth can-i list pods --as system:serviceaccount:lab-01:deployer -n lab-01
```

Expected: `deployer` for subjects, and `yes` for the last command.

## Part B — SCC

5. Create ServiceAccount `privileged-app` in `lab-01`.
6. Create a Role `use-anyuid` that can `use` the `anyuid` SCC.
7. Bind it to `privileged-app` via RoleBinding `sa-anyuid`.
8. Verify the SA may use the SCC.

```bash
# verification
oc auth can-i use scc/anyuid --as system:serviceaccount:lab-01:privileged-app -n lab-01
```

Expected: `yes`.

## Part C — Quota and limit range

9. Create a ResourceQuota `rq01` in `lab-01`: `pods=5, requests.cpu=1, requests.memory=1Gi`.
10. Create a LimitRange `lr01`: default memory request `256Mi`, limit `512Mi`.

```bash
# verification
oc get quota -n lab-01 rq01 -o jsonpath='{.spec.hard.pods}'
oc get limitrange -n lab-01 lr01 -o jsonpath='{.spec.limits[0].default.memory}'
```

Expected: `5` and `512Mi`.
